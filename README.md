Zest 游戏框架介绍
这是基于Cocos creator3.X版本的一款功能完整的游戏开发框架，包含了丰富的游戏开发基础模块。

框架核心能力
Zest 游戏框架集成了游戏开发全流程所需的核心基础模块，帮助开发者快速搭建稳定的游戏项目，无需从零开始重复实现通用能力，核心覆盖模块如下：
1.  资源内存管理模块：管控游戏运行时的资源内存占用，自动进行资源调度与回收，避免内存溢出与内存泄漏问题
2.  UI管理模块：提供统一的UI层级管控、界面跳转、生命周期管理能力，简化复杂UI逻辑的开发流程
3.  事件系统：实现观察者模式的事件分发与订阅机制，降低模块间的耦合度，提升代码可维护性
4.  网络模块：封装了常用的网络通信能力，适配游戏开发中常见的长连接、短连接通信场景
5.  资源管理模块：提供统一的资源加载、卸载、缓存能力，支持不同类型游戏资源的标准化调度
6.  多分辨率适配模块：自动适配不同尺寸、不同比例的终端屏幕，保证游戏画面在各类设备上的显示效果一致
7.  数据存储模块：封装本地持久化存储能力，支持游戏配置、玩家进度等数据的安全读写
8.  引导模块：提供标准化的新手引导流程编排能力，快速实现可配置化的游戏新手引导逻辑
9.  红点管理模块：统一管控全游戏的红点触发条件、展示逻辑，无需在各业务模块重复编写红点判断代码
10. ECS架构：集成实体组件系统架构，适配中大型游戏的高性能、高扩展性开发需求
11. 通用组件库：额外提供包括遥感组件在内的一系列开箱即用的游戏通用交互组件，直接复用即可实现对应的交互效果

仓库目录说明
项目仓库内的文件包含完整的框架源码、配套资源与说明文档，同时提供了示例项目供开发者快速上手参考，帮助开发者直观了解各个模块的使用方式。

使用指引
你可以直接将项目克隆到本地，参考仓库内提供的使用说明链接，结合示例项目即可快速上手基于Zest框架进行游戏项目开发。
